Find an existing reservation made on an earlier call. Needs both the name it was made under and the date. Without a booking code the result can only be read back; with the right code the booking can then be cancelled. Not needed for a booking made during this call — use its reference directly. The name is matched loosely, so pass it as the guest said it, in the form they said it. When nothing matches, the result carries a 'say' that names the date that was searched: say it, and let the guest confirm or correct the date. Search again only with a date the guest has given; never try neighbouring dates on your own.
